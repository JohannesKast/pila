# Security Policy

## Supported Versions

Pila is currently pre-v1.0. Security fixes are applied on the `master` branch.
Please assume that only the latest commit on `master` receives fixes.

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Report them privately via GitHub's private vulnerability reporting for this
repository and include:

- a short summary of the issue
- affected deployment mode or component
- reproduction steps or proof of concept
- impact assessment if known

I will acknowledge receipt, investigate, and decide on the fix and disclosure
timeline.
